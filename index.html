先减脂，还是先练力量？

结论：不用分先后，两件事同时做。
  • 减脂靠热量缺口（由饮食决定），增肌靠力量训练（由训练决定）——两条独立的线，互不冲突
  • 体脂偏高 + 新手，正好是「身体重组」效果最好的窗口：在热量缺口下也能长肌肉
  • 如果只减脂、不练力量 → 掉的体重里 1/4～1/3 是肌肉 → 变成「瘦而松」，基础代谢下降，后面越减越难
  • 力量训练本身就是减脂手段：它保住肌肉，而肌肉是消耗热量的引擎
  • 三件事一起做：力量训练保肌肉 ＋ 饮食缺口减脂肪 ＋ 步数和有氧加大消耗
体重不变，腰围下降✅ 正在同时减脂增肌，最好的结果
体重下降，腰围下降✅ 正常减脂
体重下降，腰围没动⚠️ 可能在掉肌肉：加蛋白、加强力量训练
只有体脂已经低于 15%、还想更精瘦时，才需要分「减脂期 / 增肌期」轮流来。别只盯着秤——腰围比体重重要。

动作要点速查（点「详细步骤」看完整分步）

徒手怎么选难度

  • 没有重量可以加，所以靠换变式来调难度
  • 判断标准：当前变式能标准做 3 组 × 12 次，就升级到下一级
  • 做完还剩 5 次余力＝太轻松，升一级；做不到 8 次＝太难，降一级
  • 下降阶段慢 2～3 秒，这是最容易被忽略但最有效的一步
  • 每组结束时还剩 1～3 次余力，不要每组都练到力竭

动作进阶阶梯（照着往上升）

推（胸/三头）手撑桌子 → 跪姿俯卧撑 → 标准俯卧撑 → 下斜俯卧撑 → 钻石俯卧撑
推（肩）跪姿派克 → 标准派克 → 脚垫高的派克 → 靠墙倒立撑
拉（背/二头）屈膝踩地反向划船 → 腿伸直的 → 脚搭椅子上的 → 反握练二头
腿自重深蹲 → 相扑深蹲 → 箭步蹲 → 保加利亚分腿蹲 → 单腿蹲
腿后侧/臀双腿臀桥 → 单腿臀桥 → 臀桥行进 → 单腿硬拉
核心死虫式 → 平板支撑 → 抬脚平板 → 侧平板 → 单臂平板
小腿双腿提踵 → 单腿提踵 → 单腿提踵放慢到 4 秒
每一列都从最简单的开始，能标准做 3 组 × 12 次再往右升一级。

徒手增加难度的 8 个手段

  1. 换更难的变式（杠杆原理：脚抬高、手放低、身体越水平越难）
  2. 加次数：8 → 15 次
  3. 加组数：3 → 4 组
  4. 放慢离心：2 秒 → 4 秒
  5. 顶峰停顿 1～2 秒
  6. 单侧化：双手改单手，双腿改单腿
  7. 缩短休息 90 → 60 秒
  8. 减少支撑点：四点撑改三点撑，脚并起来

⚠️ 徒手方案的短板（必须知道）

背部宽度⚠️ 最弱。没有单杠就练不到背阔肌的宽度，只能靠桌下反向划船勉强凑
二头肌⚠️ 很弱。只有反握反向划船能练到
腿和臀✅ 单侧动作够难，基本不吃亏
胸和三头✅ 俯卧撑变式够用
小腿✅ 单腿提踵够用
减脂效果✅ 完全不受影响。减脂靠的是饮食缺口和步数
花 100～150 元能补齐 80% 的短板：① 门上单杠（50～100 元）——练引体，解决背部宽度 ② 弹力带一套（30～50 元）——补齐面拉、划船、二头。这两样占地几乎为零。
